# cohort_creator

Creates a neuroimaging cohort by aggregating data across datasets.

The list of datasets it can get data from comes from the
[bids-inventory](https://github.com/neurodatascience/cohort_creator/tree/main/packages/bids_inventory) package.

See the [main README](https://github.com/neurodatascience/cohort_creator)
and the [documentation](https://cohort-creator.readthedocs.io/en/latest/).
